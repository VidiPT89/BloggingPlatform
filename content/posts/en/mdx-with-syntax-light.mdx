MDX is the honest format for a developer journal. You write like a person. When a sample matters, you drop a fence and keep going.

```js
export function slugify(title) {
  return title
    .toLowerCase()
    .normalize("NFD")
    .replace(/\p{Diacritic}/gu, "")
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/(^-|-$)/g, "");
}
```

Syntax highlighting is not decoration. It is how a reader finds the verb in a block of types. This desk uses `rehype-pretty-code` and Shiki on a near-black field so the ember tokens stay readable.
