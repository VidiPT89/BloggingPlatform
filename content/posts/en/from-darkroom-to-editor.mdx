I used to wait for the image to appear in the tray. Now I wait for the type checker. The room changed. The patience did not.

A good frame is a decision about what to leave out. A good pull request is the same decision, only the crop is a function and the grain is a test.

```ts
type Frame = {
  subject: string;
  leftover: string[];
};

function crop(frame: Frame) {
  return frame.subject;
}
```

This journal is where those two rooms meet: light, sequence, and a headline that earns its place.
