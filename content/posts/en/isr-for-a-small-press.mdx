A personal blog does not need a CDN war room. It needs pages that feel printed, then quietly reprint when a note changes.

Next.js ISR does that with a revalidate window. The first reader after the window expires gets a fresh page. Everyone else reads from cache.

```ts
export const revalidate = 3600;
```

That single constant is the press schedule. Notes stay static. The shelf still updates.

If you ship MDX from disk, keep the content folder next to the app and treat each file as a plate: one slug, one locale, one date.
