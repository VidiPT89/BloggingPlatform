Antes esperava que a imagem aparecesse no tabuleiro. Agora espero pelo verificador de tipos. A sala mudou. A paciência não.

Um bom enquadramento é uma decisão sobre o que fica de fora. Um bom pull request é a mesma decisão: o recorte é uma função e o grão é um teste.

```ts
type Frame = {
  subject: string;
  leftover: string[];
};

function crop(frame: Frame) {
  return frame.subject;
}
```

Este caderno é o sítio onde as duas salas se encontram: luz, sequência e um título que justifica o espaço.
