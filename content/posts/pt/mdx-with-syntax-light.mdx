MDX é o formato honesto para um caderno de developer. Escreves como pessoa. Quando um exemplo importa, abres uma cerca e segues.

```js
export function slugify(title) {
  return title
    .toLowerCase()
    .normalize("NFD")
    .replace(/\p{Diacritic}/gu, "")
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/(^-|-$)/g, "");
}
```

O destaque de sintaxe não é decoração. É a forma de o leitor encontrar o verbo num bloco de tipos. Esta secretária usa `rehype-pretty-code` e Shiki sobre um campo quase preto, para os tokens em brasa se lerem bem.
