Um caderno sem saída é uma gaveta. O RSS é a porta. Cada nota leva título, ligação, data e categoria para quem quiser subscrever sem criar conta aqui.

As imagens Open Graph são o cartaz na rua. Esta app pinta uma por slug: campo preto, filete laranja queimado, o título numa face de display.

Os comentários são opcionais. O Giscus liga GitHub Discussions a um post. Se as variáveis de ambiente estiverem vazias, a mesa fecha e a nota continua de pé sozinha.
